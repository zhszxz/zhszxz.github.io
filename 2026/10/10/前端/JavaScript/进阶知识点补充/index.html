三、防抖 debounce

概念：触发后 n 秒内没有再次触发，才执行（只执行最后一次）。

场景：搜索框输入、窗口 resize、按钮防连点。

四、节流 throttle

概念：n 秒内最多执行一次（固定频率）。

场景：滚动监听、鼠标移动（高频触发但无需每次都响应）。

防抖 vs 节流

防抖 debounce 节流 throttle
触发时机 停止触发 n 秒后才执行 每 n 秒固定执行一次
比喻 电梯等人（等人齐了才关门） 红绿灯（固定间隔放行）
场景 搜索框、resize 滚动、mousemove

记忆：防抖是”最后一下”，节流是”固定频率”。两者都用闭包保存定时器/时间戳。

九、复习要点

  1. 原型链：实例.__proto__ → 构造函数.prototype → Object.prototype → null；instanceof 就是沿链查找；new 做了四件事。
  2. 浅拷贝只复制第一层（.../Object.assign），内层仍共享；深拷贝用 structuredClone（或递归/JSON，注意 JSON 丢函数）。
  3. 防抖停止 n 秒后才执行（搜索框），节流每 n 秒执行一次（滚动），都用闭包实现。
  4. Symbol 是唯一值，做对象唯一属性名，且不会被 Object.keys 遍历。
  5. 迭代器有 next() 返回 { value, done }；for...of 靠 Symbol.iterator；生成器 function* 能暂停恢复。
  6. 严格模式让 this 更安全、未声明变量报错。
  7. 柯里化是”一次一个参数”，组合是”从右到左拼函数”。
  8. 类型判断：基本类型用 typeof、原型链用 instanceof、最准用 toString.call。
