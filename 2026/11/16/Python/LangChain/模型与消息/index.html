一、模型初始化

模型（Chat Model）是所有 LLM 应用的基础。LangChain 提供了 init_chat_model 统一入口，也支持直接实例化具体模型类。掌握三种初始化方式，就能接入几乎所有模型。

1.1 方式一：默认初始化（最简单）

只传模型名字，LangChain 会根据名字自动推断厂商并读取对应的环境变量（摘自练习代码 day05/03.模型-默认初始化.ipynb）：

前提是 .env 里配好了对应的 DEEPSEEK_API_KEY。

1.2 方式二：自定义初始化（伪装 OpenAI）

很多模型（如阿里云 DashScope、各兼容 OpenAI 接口的服务）LangChain 没有专门集成，但都提供 OpenAI 兼容接口。此时用 model_provider="openai"，手动传 api_key 和 base_url 即可「伪装成 OpenAI」（摘自练习代码 day05/04.模型-自定义初始化.ipynb）：

这是企业里最常用的技巧：只要某个服务支持 OpenAI 兼容接口，就能通过「换 base_url + api_key」接入，无需等官方集成。

1.3 方式三：Model 类初始化（具体类）

直接实例化某个厂商的模型类，适合需要精细控制、或使用本地模型的场景（摘自练习代码 day05/05.模型-Model类初始化.ipynb）：

三种方式对比：

方式 适用场景 特点
默认初始化 官方已集成的模型 最省事，自动读环境变量
自定义初始化（伪装 OpenAI） 兼容 OpenAI 接口的服务 灵活，靠 base_url 切换
Model 类初始化 本地模型 / 精细控制 显式、可读性强

三、消息类型

LangChain 的消息用 langchain.messages 下的类表示，对应 LLM 对话的四种角色（摘自练习代码 day05/07.模型-各种消息类型.ipynb）：

消息类 角色 role 含义
SystemMessage system 系统指令，设定 AI 的人设/规则，放在最前面
HumanMessage user 用户输入
AIMessage assistant AI 的回复
ToolMessage tool 工具执行结果（第 3 篇详解）

四、结构化输出

结构化输出让模型返回符合指定格式（Schema）的数据，而不是自由文本，从而能直接解析成对象、写入数据库、供程序消费。这是企业级应用的核心能力之一（摘自练习代码 day05/08.模型-结构化输出.ipynb）。

4.1 用 Pydantic 定义输出结构

Field(description=...) 是对每个字段的说明，模型会据此填充对应内容。

4.2 绑定到模型

要点：

  • with_structured_output(schema=...) 返回一个「会输出结构化对象」的新模型。
  • invoke 的返回值直接是 Pydantic 对象（不再是 AIMessage），可直接 response.name 访问字段。
  • 底层原理：LangChain 把 Schema 转成 JSON Schema 传给模型，模型输出 JSON，再解析回 Pydantic 对象。

4.3 应用场景

结构化输出几乎无处不在：信息抽取（从文本提取实体）、情感分析（返回 {sentiment: "positive", score: 0.9}）、JSON API 返回、表单数据生成、分类等。凡是要「让模型吐出结构化数据」的场景都用它。

五、模型的流式与异步调用（补充）

invoke 是同步阻塞调用，返回完整结果。此外模型还支持：

  • **stream()**：流式返回，逐 token 输出（适合打字机效果）。
  • **ainvoke() / astream()**：异步版本（async/await），配合协程提升并发。

说明：Agent 层的流式调用（agent.stream_events）会在第 3 篇详细讲，两者入口不同但思想一致。

小结

本篇覆盖模型与消息的核心用法：

  1. 三种初始化方式：默认初始化（官方集成）、自定义初始化（伪装 OpenAI，靠 base_url 切换）、Model 类初始化（本地/精细控制）。
  2. invoke 调用：入参可为 str / list[dict] / list[Message]，返回值是 AIMessage，用 .content 取文本。
  3. 四种消息类型：System / Human / AI / Tool，多轮对话的上下文就是这些消息的列表。
  4. 结构化输出：with_structured_output + Pydantic BaseModel，让模型直接返回可解析的对象。
  5. 流式与异步：stream / ainvoke 是 invoke 的补充形态。
