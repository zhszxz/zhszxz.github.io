一、LangChain 是什么

LangChain 是当前最主流的 LLM（大语言模型）应用开发框架，目标是让你用统一、简洁的方式把大模型集成到自己的程序里，并快速搭建 Agent、RAG 等高级应用。

它的价值概括为三点：

  1. 统一 API：不同模型厂商（OpenAI、DeepSeek、Ollama、阿里云 DashScope 等）的接口各不相同，LangChain 提供统一的模型、消息、工具抽象，切换模型几乎不用改代码。
  2. 工具箱：把社区沉淀的常见模式（工具调用、会话记忆、Agent、RAG、结构化输出等）提炼成即用组件，不用从零造轮子。
  3. 生态整合：通过一个个独立的集成包，对接向量库（Milvus）、嵌入模型（Ollama/DashScope）、MCP 服务器、文档加载器等第三方能力。

一句话：LangChain 不是「又一个模型 SDK」，而是站在模型 SDK 之上的一层抽象与编排框架。

1.1 1.x 统一 API vs 0.x 旧 API（重要，必看）

LangChain 在 2025 年底发布了 1.0 版本，对 API 做了大幅重构，新旧写法差异很大。网上大量教程仍停留在 0.x 时代，看教程时务必分清版本，否则代码根本跑不起来。

能力 0.x 旧写法（已过时） 1.x 新写法（本笔记采用）
初始化模型 ChatOpenAI(model="gpt-4") init_chat_model("deepseek-v4-flash")
创建 Agent create_openai_functions_agent + AgentExecutor create_agent(model=..., tools=...)
工具 @tool + StructuredTool @tool（langchain.tools）
消息 langchain.schema 下的消息类 langchain.messages 下的消息类
提示词 PromptTemplate + LLMChain（已废弃） 直接用消息列表 / system_prompt

本笔记全部基于 LangChain 1.x 新 API。你练习代码里 langchain 包的版本是 1.5.x、langchain-core 是 1.8.x，属于 1.x 生态。

1.2 分层架构

LangChain 1.x 把包拆成了几个层次，理解这个结构对排查依赖问题很有帮助：

包 作用
langchain-core 核心抽象：消息、模型基类、工具、文档、向量存储接口等（所有包的地基）
langchain 高层 API：init_chat_model、create_agent、langchain.tools 等，日常直接用这个
langchain-openai / langchain-deepseek / langchain-ollama 等 各模型厂商的集成包
langchain-text-splitters 文档切分器
langchain-milvus Milvus 向量库集成
langchain-mcp-adapters MCP 协议适配器

注意：langchain-community 正在被逐步废弃（sunset），新代码优先使用独立的集成包（如 langchain-ollama），不要再用 langchain_community。

小结

本篇是 LangChain 的地基，需要记住：

  1. LangChain 是 LLM 应用的抽象与编排框架，核心价值是统一 API + 工具箱 + 生态。
  2. 1.x 新 API 与 0.x 旧 API 差异巨大：init_chat_model / create_agent 是新写法，ChatOpenAI / LLMChain 是旧写法，看教程先辨版本。
  3. 分层包结构：langchain-core（地基）→ langchain（高层）→ 各集成包；langchain-community 正被废弃。
  4. 工具调用本质：模型不执行函数，只返回 tool_calls，由代码执行工具后把结果传回模型，如此循环。
  5. 统一范式：@tool 定义工具 → create_agent 组装 → invoke({"messages": [...]}) 调用。
