一、文件操作

1.1 打开文件 open()

模式 含义
r 只读（默认），文件必须存在
w 覆盖写，不存在会创建
a 追加写，不存在会创建
b 二进制模式（可与其他组合，如 rb、wb）
+ 读写模式（如 r+、w+）

**务必显式指定 encoding="utf-8"**，否则依赖系统默认编码，Windows 上读中文易乱码。

1.2 读文件

三个方法对比：

  • read()：一次性全读，适合小文件。
  • readline()：一次一行。
  • readlines()：返回行列表。

**大文件不要用 read()**，会占满内存，应逐行遍历（见 1.4）。

1.3 写文件

write() 不会自动加换行，需手动加 \n；writelines(列表) 可批量写一个字符串列表。

五、正则表达式

正则用于字符串的模式匹配，是数据清洗、日志解析、表单校验的核心工具。Python 用 re 模块。

5.1 核心函数

函数 作用
re.match(pattern, s) 从开头匹配，返回第一个 match 对象
re.search(pattern, s) 在任意位置匹配，返回第一个 match 对象
re.findall(pattern, s) 返回所有匹配结果的列表
re.finditer(pattern, s) 返回所有匹配的迭代器（含位置信息）
re.sub(pattern, repl, s) 替换匹配的内容
re.split(pattern, s) 按匹配切分
re.compile(pattern) 预编译正则（复用提高性能）

match 与 search 的区别是高频考点：match 只在字符串开头匹配，search 扫全串。

5.2 常用元字符与量词

语法 含义
. 任意字符（除换行）
\d 数字
\w 字母/数字/下划线
\s 空白字符
\D \W \S 对应的「非」
[abc] 字符集，匹配 a/b/c 之一
[^abc] 不在字符集内
[3-9] 范围，3 到 9
^ / $ 字符串开头 / 结尾
\b 单词边界

量词（限定前面元素出现次数）：

量词 含义
* 0 次或多次
+ 1 次或多次
? 0 次或 1 次
{n} 恰好 n 次
{n,} 至少 n 次
{n,m} n 到 m 次
