1、JWT 原理

JWT：

JSON Web Token

由三部分组成：

服务端登录成功后：

  • 生成 token
  • 返回给前端
  • 前端后续请求携带 token
  • 服务端解析 token 获取用户信息

JWT 是目前前后端分离项目最主流的认证方式。
