一、闭包

1.1 什么是闭包

闭包 = 函数 + 它引用的外部变量。当一个内层函数引用了外层函数的变量，并且外层函数把内层函数返回，这个内层函数（连同它捕获的外部变量）就构成了闭包（摘自练习代码 chapter02/26.闭包和装饰器.py）：

  • 可迭代对象（Iterable）：能被 for 遍历的对象，如 list、str、dict、tuple、set。它们实现了 __iter__ 方法。
  • 迭代器（Iterator）：能不断 next() 取值、且取完抛 StopIteration 的对象。实现了 __iter__（返回自身）和 __next__。

关系：迭代器一定是可迭代对象，可迭代对象不一定是迭代器。

五、上下文管理器

上下文管理器用于管理资源的获取与释放（文件、锁、数据库连接等），保证无论是否异常，资源都能被正确释放。

5.1 with 语句（最常用）

with 是 try...finally 的语法糖，更简洁、更安全。

5.2 原理：enter 与 exit

任何实现了 __enter__ 和 __exit__ 的对象都能用于 with：

  • with obj as x：进入时调用 obj.__enter__()，返回值赋给 x。
  • 退出 with 块时调用 obj.__exit__(...)，即使块内抛异常也会调用。

小结

高级语法是 Python 从「会用」到「精通」的分水岭：

  1. 闭包：函数 + 捕获的外部变量，能保存状态，是装饰器的底层。
  2. 装饰器：@ 语法糖 + *args/**kwargs + @wraps，可实现计时、日志、缓存、重试等横切功能；带参装饰器是三层嵌套。
  3. 迭代器：可迭代对象 ≠ 迭代器；iter()/next() 与 StopIteration 是 for 循环的底层。
  4. 生成器：yield / 生成器表达式，惰性求值、省内存，处理大数据和无限序列的核心。
  5. 上下文管理器：with + __enter__/__exit__，或用 @contextmanager；保证资源正确释放。
