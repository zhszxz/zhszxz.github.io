五、递归

递归是函数调用自身的编程方式，必须有基准条件（终止条件）防止无限递归：

递归的两个要点：

  1. 基准条件：递归到某一步必须能停止。
  2. 规模递减：每次调用让问题向基准条件靠近。

Python 对递归深度有限制（默认约 1000 层，sys.setrecursionlimit 可调），且没有尾递归优化，深层递归会栈溢出。因此能用循环解决的优先用循环，递归主要用于树、图、分治等天然递归的结构（如遍历目录、解析嵌套结构）。

六、类型注解

类型注解是给变量、函数参数和返回值标注类型，只是提示、不是强制约束——它不会改变 Python 的动态类型特性，但能帮助 IDE 补全、让工具（mypy、pylint）做静态检查，大幅减少类型错误（摘自练习代码 chapter02/18.类型注解.py）。

6.1 变量注解

注解是「提示」不是「约束」：给 list[int] 追加 10010.0（float）也不会报错，运行时照常执行。

6.2 函数注解

格式：def 函数名(参数: 类型) -> 返回值类型。

小结

函数篇的核心是参数体系，这是 Python 与多数语言差异最大、最易失分的地方：

  1. 参数五种形式：位置、默认、*args、**kwargs、keyword-only，及调用时的 */** 解包。
  2. 可变默认参数陷阱：默认值必须是不可变对象或 None。
  3. 作用域 LEGB：读全局无需声明，写全局要 global，改闭包外层要 nonlocal。
  4. lambda 与高阶函数：函数是一等对象，sort(key=)、map/filter、partial/lru_cache 是生产高频。
  5. 类型注解：变量: 类型、参数: 类型 -> 返回类型、list[int]、X | None 联合类型，只是提示不做强制。
