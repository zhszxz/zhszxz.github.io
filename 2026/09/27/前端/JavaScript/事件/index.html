事件

事件是用户与页面交互的桥梁：点击、输入、滚动、按键都会触发事件，JS 通过监听事件来响应用户操作。

这一篇讲事件的注册与解绑、事件类型、事件对象、事件流（冒泡/捕获）、事件委托。其中事件流和事件委托是重点，也是 JS 与 Java GUI（如 Swing 的监听器）最大的差异。

一、注册与解绑事件

1. 三种注册方式

⚠️ onclick 方式后写会覆盖前一个；addEventListener 可同时绑定多个，是标准做法。

2. 解绑 removeEventListener

⚠️ 关键坑：解绑必须传同一个函数引用。匿名函数无法解绑（addEventListener 里写 () => {} 就再也解不掉了）。需要解绑时，务必用命名函数。

二、事件类型

1. 鼠标事件

事件 触发时机 备注
click 单击 最常用
dblclick 双击
mouseenter / mouseleave 移入 / 移出 不冒泡，推荐
mouseover / mouseout 移入 / 移出 冒泡，会受子元素影响
mousemove 移动 配合坐标做拖拽
mousedown / mouseup 按下 / 松开
contextmenu 右键

2. 键盘事件

事件 触发时机
keydown 按下（推荐）
keyup 松开
keypress 字符键按下（已废弃，少用）

3. 表单事件

事件 触发时机
input 每次输入（实时）
change 值改变且失焦后
submit 表单提交
focus / blur 获得 / 失去焦点

4. 页面事件

事件 触发时机
load 页面全部加载完（含图片等资源）
DOMContentLoaded DOM 构建完（比 load 早）
scroll 滚动
resize 窗口大小改变

四、事件流（捕获与冒泡）

一次完整的事件传播分三个阶段：捕获阶段 → 目标阶段 → 冒泡阶段。

⚠️ 记忆点：默认（false）是冒泡，事件从目标元素向上传到父元素，也是事件委托的基础。

阻止冒泡：e.stopPropagation() 让事件不再向上传播：

区分：stopPropagation 阻止传播，preventDefault 阻止默认行为，两者互不影响。

五、事件委托（重点）

原理：利用事件冒泡，把监听器绑在父元素上，通过 event.target 判断实际点击的子元素。

委托的两大好处：

  1. 性能：只绑一个监听器，替代绑 N 个。
  2. 动态元素友好：后加入的子元素自动生效，无需重新绑定。

⚠️ target vs currentTarget（委托里最易混）：

  • e.target：实际点到的元素（点谁是谁）。
  • e.currentTarget：绑定监听器的元素（委托里是父元素 ul）。

事件委托判断目标时一定要用 e.target。

六、速查表

需求 写法
注册事件 el.addEventListener("click", fn)
解绑事件 el.removeEventListener("click", fn)（要同名函数）
阻止默认 e.preventDefault()
阻止冒泡 e.stopPropagation()
触发目标 e.target
绑定元素 e.currentTarget
按键名 e.key
鼠标坐标 e.clientX / e.clientY
捕获阶段 addEventListener("click", fn, true)
事件委托 父元素监听 + e.target 判断

七、复习要点

  1. 注册事件用 addEventListener（可绑多个），解绑要同名函数引用（匿名函数解不掉）。
  2. 常用事件：鼠标 click/mouseenter/mousemove、键盘 keydown、表单 input/change/submit、页面 load/DOMContentLoaded/scroll。
  3. e.target 是实际触发元素，e.currentTarget 是绑定元素；preventDefault 阻止默认，stopPropagation 阻止冒泡。
  4. 事件流三阶段：捕获 → 目标 → 冒泡，默认在冒泡阶段触发。
  5. 事件委托：监听父元素 + e.target 判断，省性能、支持动态元素。
  6. 忘了某个事件或属性，回本文对应小节查示例即可。
