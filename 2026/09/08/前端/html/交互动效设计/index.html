交互动效设计

网页动效的核心是：让页面元素”动起来”，从而引导视线、反馈操作、增强体验。

动效本质上是改变元素的某个 CSS 属性，并控制它变化的节奏。实现手段主要有两条路线：

  • 过渡 transition：由状态变化（如 :hover、:focus、类名切换）触发，平滑地从一个值过渡到另一个值。
  • 动画 animation：定义好关键帧后自动播放，可以无限循环、延迟、反向等。

配合 transform 变换、filter 滤镜、clip-path 裁剪、SVG 描边动画、滚动驱动动画等，就能做出各类炫酷效果。

这篇笔记覆盖 2D/3D 变换、过渡、动画、逐帧动画、流光边框、3D 相册与导航、SVG 描边动画、裁剪、滤镜、CSS 变量与 calc、滚动时间线等动效相关知识点，适合快速复习。

一句话记忆：transition 是”从 A 过渡到 B”（需要触发），animation 是”自己会动”（自动播放）。

3. 哪些属性可以过渡

  • 可过渡：数值类属性（width、height、color、opacity、transform、background-color、margin、left、filter 等）。
  • 不可过渡：display、background-image（渐变/图片切换）、position 等离散属性。

⚠️ 易忘点：想让元素”淡入淡出”不要过渡 display，改用 opacity 或 visibility。

二、transform 2D 变换

transform 用于改变元素的形状、位置、角度，不改变元素在文档流中的占位，不影响布局。

1. 位移 translate

  • 位移以元素自身位置为基准。
  • 百分比相对于自身宽高（常用于垂直居中：translateY(-50%)）。

2. 旋转 rotate

transform-origin 取值：关键字（center/left/right/top/bottom）、像素、百分比。

3. 缩放 scale

  • 参数是比例，1 表示原大小，小于 1 缩小、大于 1 放大。
  • 同样不影响布局占位。

4. 斜切 skew

常用于做出倾斜的文字标签、卡片侧边等。

子属性 作用 常用值

值 效果

cubic-bezier(x1,y1,x2,y2) 自定义贝塞尔曲线

八、滤镜 filter 与背景滤镜 backdrop-filter

1. filter 常见函数

函数 作用
blur() 高斯模糊，数值越大越糊

2. drop-shadow 与 box-shadow 区别

  • box-shadow：给盒子加阴影（矩形）。
  • drop-shadow：按元素实际形状/透明区域轮廓加阴影，对带透明背景的 PNG、SVG 更真实。

2. calc 计算函数

  • calc() 里 +、- 两边要加空格（*、/ 可不加）。
  • 可混合单位，如 calc(100% - 20px)。

十一、单位与独立变换属性

1. vw / vh 视口单位

  • vw：相对视口宽度，100vw = 整个视口宽。
  • vh：相对视口高度，100vh = 整个视口高。
  • 常用于整屏布局、响应式字号：font-size: calc(1em + 0.5vw)。

2. turn 角度单位

1turn = 360deg，写整圈时比 360deg 更直观。
